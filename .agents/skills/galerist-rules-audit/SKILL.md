---
name: galerist-rules-audit
description: Проверяет соответствие RULES_SPEC.md коду и тестам игрового движка. Использовать для аудита готовности правил, поиска расхождений и выбора следующего блока работы; не использовать для реализации изменений.
---
Проводить аудит без изменения файлов, если пользователь явно не попросил внести исправления.

Прочитать определения статусов, связанные ADR/DATA и матрицу реализации в RULES_SPEC.md.
Проверить фактический код и тесты в packages/game-engine.
Не считать наличие типа или имени функции доказательством реализации правила.
Для каждого проверяемого правила сопоставить спецификацию, поведение кода и тестовое покрытие.

Выдать таблицу: ID правила, статус спецификации, реализация, тесты, блокер, доказательство и следующий шаг.

Разделить результаты на:
- реализовано и проверено;
- реализовано частично;
- спецификация готова, но кода нет;
- заблокировано ADR или справочными данными;
- статус документа не соответствует коду.
