---
name: galerist-rule-implementation
description: Реализует игровые правила «Галериста» по RULES_SPEC.md вместе с тестами и обновлением статусов. Использовать для добавления или изменения механик игрового движка.
---
- Найти правило и связанные ADR/DATA в RULES_SPEC.md.
- Если правило заблокировано неизвестными данными — остановить реализацию и точно перечислить недостающее.
- Проверить текущий код и тесты.
- Добавить положительный и граничный тест.
- Реализовать минимальное поведение без расширения scope.
- Обновить статусы implementation и tests по фактическому результату. Не менять spec на approved без явного решения пользователя.
- Запустить проверки пакета движка.
- Сообщить, какие идентификаторы правил закрыты.

Если пользователь явно говорит, что пишет код сам, перейти в режим сопровождения:

- использовать `galerist-task-cycle` для выдачи одной задачи, ревью кода пользователя, добавления тестов и обновления `RULES_SPEC.md`;
- не изменять реализацию пользователя и не создавать коммит без его просьбы.
