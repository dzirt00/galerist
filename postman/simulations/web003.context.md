# web003 — контекст локальной симуляции

Записано 2026-10-26. Mock проекта, не официальный mock Supabase.

## Purpose

Проверка настоящих game-list/join-game/ready-to-game/get-game-players и Supabase SDK через HTTP. Контракт готовности и команды запуска — в `supabase/functions/ready-to-game/README.md`, чтения состава — в `supabase/functions/get-game-players/README.md` (порт 4919).

## Execution

Команды запуска на порту 4918 и тестов приведены в `supabase/functions/join-game/README.md`.
Дождаться события `listening`; после тестов остановить симуляцию через Ctrl+C.

## Assumptions

Локальный mock проверяет HTTP-контракт, но не облачную Auth, права БД и блокировки. SQL-конкуренция проверяется отдельно через `npm run test:db`.
