# web002 — контекст локальной симуляции

Записано 2026-10-26. Mock проекта, не официальный mock Supabase.

## Purpose

Проверка настоящего create-game и Supabase SDK через HTTP после выделения общей HTTP-границы.

## Execution

Команды запуска на порту 4917 и теста приведены в `supabase/functions/README.md`.
Дождаться события `listening`; после тестов остановить симуляцию через Ctrl+C.

## Assumptions

Проверяется поведение обработчика против локальных ответов Auth/REST/RPC, а не настоящая Auth, SQL-транзакция или RLS. Происхождение mock описано в `postman/mocks/web002-supabase/README.md`.
