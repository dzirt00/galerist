# Локальный HTTP fixture для WEB-002

Этот mock написан для конкретного пути `create-game` по миграции
`20261019000100_create_games.sql`, контракту WEB-002 и формату запросов/ответов
установленных `@supabase/supabase-js`, `auth-js` и `postgrest-js`.
Готовый mock владельца Supabase из Postman workspace не использовался;
подключение к внешнему workspace и публикация не нужны для этих локальных тестов.

Он моделирует только GET Auth user, POST RPC create_game и чтение трёх таблиц.
На прочие маршруты отвечает 501. Данные и журнал запросов хранятся в `pm.state`
под ключом с префиксом `web002-supabase`. Тестовые маршруты `__test/reset`
и `__test/state` задают ответ зависимости и позволяют проверить отправленные
HTTP-запросы. Все ключи, токены и пользователи синтетические.

Повтор RPC сохраняет результат только для проверки дальнейшего поведения
обработчика: чтения исходной комнаты и возврата прежнего DTO. Реальная
уникальность, конкуренция, транзакция и RLS проверяются отдельно через
`npm run test:db`, а не этим mock. Подлинность реального токена и поведение
облачного Supabase также остаются за пределами симуляции.

Запуск описан в `supabase/functions/README.md`. Использовать только локально;
mock содержит тестовые маршруты управления, он не предназначен для развёртывания.
